# 🔗 URL Shortener

A simple and responsive URL Shortener web application that converts long URLs into short, shareable links using the TinyURL API. The application provides an intuitive interface for quickly generating and copying shortened URLs.

## ✨ Features

* Shorten long URLs instantly
* URL validation
* One-click copy to clipboard
* Responsive and user-friendly interface
* Fast URL generation using the TinyURL API
* Opens shortened links in a new browser tab

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript**
* **TinyURL API**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/url-shortener.git
```

### 2. Navigate to the project directory

```bash
cd url-shortener
```

### 3. Run the application

Open the `index.html` file in your preferred web browser.

No installation or build tools are required.

## 📖 How It Works

1. Enter a valid long URL.
2. Click the **Shorten URL** button.
3. The application sends the URL to the TinyURL API.
4. A shortened URL is generated and displayed.
5. Copy the shortened link or open it directly in a new tab.
